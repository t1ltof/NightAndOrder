# Night and Might

Игра для Android в духе Vampire Survivors. Две стороны: вампиры и Святой орден.

Релизы: [github.com/t1ltof/NightAndOrder/releases](https://github.com/t1ltof/NightAndOrder/releases)

При запуске игра сама проверяет GitHub и предлагает обновиться.

## Как играть

- Шесть героев, оружие бьёт само, опыт капает со сфер, каждые 8 минут наступает рассвет.
- Слева виртуальный стик. На эмуляторе — WASD.
- Сундук раз в полторы минуты: слияние оружия, короткий обряд или кровавая клятва.
- С 7:00 вампирам на ярком экране тяжело, Ордену — наоборот.
- Телефон — часть обряда: ночь за окном, луна, заряд, тишина. Не всё написано на экране.
- После забега герой и фракция получают очки на наследие в меню выбора.
- Не все герои в хронике с первой ночи. Рекорды, следы и ночь дня — в меню «Хроника».

## Сборка

Нужны JDK 17 и Android SDK. Путь к SDK — в `local.properties`.

```bat
gradlew.bat assembleRelease
```

APK: `app\build\outputs\apk\release\app-release.apk`

Для подписи релиза скопируйте `signing.properties.example` в `signing.properties` и положите ключ в `keystore/`.
